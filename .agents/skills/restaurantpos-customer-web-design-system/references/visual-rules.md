# Visual Rules

## Layout

- Page max width: keep customer task content readable, usually one narrow column on mobile and a constrained two-column layout on desktop.
- Spacing: use a small rhythm such as `gap-3`, `gap-4`, `gap-6`, and avoid one-off spacing.
- Top sections: title, short helper line, status or primary action.
- Bottom navigation: reserve for the highest-frequency protected app areas only.

## Surfaces

- Use page background, section background, and item surface as separate layers.
- Prefer unframed sections for page structure.
- Use cards for repeated items, forms, payment panels, and modal content.
- Use borders and subtle shadows sparingly.

## Color

- Use neutral readable backgrounds with one restaurant accent.
- Use status colors only for status: success, warning, danger, pending.
- Ensure disabled surfaces look intentionally unavailable.

## Typography

- Use short headings.
- Body text should be scannable at mobile width.
- Do not scale font size with viewport width.
- Letter spacing should be 0.
