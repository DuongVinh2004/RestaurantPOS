# Status Visuals

Use consistent status treatment.

| Domain | Status | Visual Treatment | Customer Copy |
|---|---|---|---|
| Auth | expired | warning alert | `Please sign in again.` |
| Reservation | confirmed | success badge | `Confirmed` |
| Reservation | pending | neutral badge | `Pending` |
| Reservation | cancelled | muted badge | `Cancelled` |
| Deposit | required | warning badge | `Deposit needed` |
| Deposit | paid | success badge | `Deposit paid` |
| Bill | ready | primary action | `Ready to pay` |
| Payment | processing | pending badge plus refresh | `Payment processing` |
| Payment | failed | danger alert | `Payment did not go through` |
| Feature | blocked | muted panel | `Not available yet` |

Do not use color alone. Pair status color with text.
