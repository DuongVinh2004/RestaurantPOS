# UI_SCOPE.md — Customer Web

## Core flows to prioritize
1. Landing / home
2. Menu browse
3. Product detail / customization
4. Combo / promo discovery
5. Cart
6. Checkout
7. Order confirmation
8. Order tracking
9. Reservation / booking if applicable
10. Profile / order history / loyalty

## Shared primitives required
- StorefrontLayout
- HeroSection
- CategoryNav
- PromoBanner
- ProductCard
- ProductGrid
- QuantityStepper
- OptionGroup
- CartDrawer
- CartSummary
- CheckoutSection
- AddressContactForm
- PaymentSummary
- TrustBlock
- OrderStatusTimeline
- EmptyCartState
- ReservationCard
- LoyaltyCard

## Expected page behavior
- menu browsing should be fast on mobile
- add-to-cart should be obvious and low friction
- cart editability should be effortless
- checkout must feel trustworthy and uncluttered
- confirmation should clearly state next steps
- promo sections should assist discovery, not overwhelm it

## Quality bar
- no admin-style density in storefront screens
- no inconsistent product cards
- no unclear price hierarchy
- no hidden cart state
- no cluttered checkout forms
- no weak mobile interaction targets
